
# Startup Profit Prediction using Multilinear Regression
A multilinear regression model to analyze the impact of research, administration, and marketing spend on startup profitability.


## 1. Business Problem statement
* **1.1 Business Objective**: Find the impact of Research & Development (R&D) Spend, Administration, and Marketing Spend on the profit of startup companies.
* **1.2 Constraints**: If input parameters show high multicollinearity, those features must be addressed or dropped.

## 2. Data understanding
| Name of Feature | Description | Type | Relevance |
| :--- | :--- | :--- | :--- |
| R&D Spend | Amount spent on research and development | Numerical | Contributory |
| Administration | Expenses incurred on administration | Numerical | Contributory |
| Marketing Spend | Amount spent on marketing campaigns | Numerical | Contributory |
| State | Operating location state | Nominal | Not useful (dropped) |
| Profit | Profit generated by the startup | Numerical | Contributory (Target) |

## 3. Data Pre-processing & EDA
* Data cleaning, missing value checks, and outlier treatment via boxplots and Z-scores.
* Exploratory Data Analysis (EDA) including summary statistics, univariate distributions, and bivariate scatter plots against Profit.

## 4. Model Building & Evaluation
* Built multilinear regression models using scaled data.
* Checked for multicollinearity using **Variance Inflation Factor (VIF)**, **Added Variable Plots (AvPlots)**, and **Influence Index Plots**.
* Compared train and test **RMSE** and **R-Squared** values across iterations.
* Handled model tuning to maximize predictive accuracy.

## 5. Business Impact
* Enables stakeholders to forecast profits accurately at any given instance, aiding data-driven decisions on whether to continue or scale operations based on resource allocation.
